# Security Policy

The George Bakhanyiselwa Nguwe Bawo NPC project takes the security of its website, code, and community data seriously. Thank you for helping us identify and address security issues responsibly.

## Supported Versions

Security fixes are prioritized for the latest code on the `main` branch and the currently deployed version of the web app. Older commits, branches, or releases are not guaranteed to receive security updates.

| Version | Supported |
| --- | --- |
| Latest version on `main` | :white_check_mark: |
| Older commits or versions | :x: |

## Reporting a Vulnerability

**Please do not report security vulnerabilities in public GitHub Issues, Discussions, pull requests, or public comments.** Public disclosure before a fix is available may put users and project systems at risk.

1. If GitHub's **Private vulnerability reporting** feature is available for this repository, use it to submit the report privately: [Report a vulnerability](https://github.com/simthandilemthwesi/gbnb-site/security/advisories/new).
2. If private reporting is unavailable, contact the maintainer through their [GitHub profile](https://github.com/simthandilemthwesi) and request a private channel for sharing the report. Do not post exploit details publicly.

Please include, where possible:
- A clear description of the vulnerability and its potential impact.
- The affected URL, file, component, or version.
- Steps to reproduce the issue, with a proof of concept if safe to provide.
- Any relevant screenshots, logs, or suggested mitigation.
- Whether you believe the issue may expose personal information, credentials, or other sensitive data.

## What to Expect

The maintainer will review the report, may ask for additional information, and will work to assess its severity and determine appropriate remediation. We aim to acknowledge reports and provide updates as reasonably possible, but a specific response or resolution time is not guaranteed.

If the report is accepted, the project will work toward a fix and coordinate disclosure where practical. If the issue is out of scope, cannot be reproduced, or is not considered a security vulnerability, the reporter will be informed where possible and given an explanation.

Please allow reasonable time for investigation and remediation before disclosing the issue publicly. Do not access, modify, download, or disclose data that does not belong to you; do not disrupt services or perform testing beyond what is necessary to demonstrate the issue.

## Scope

Reports are most useful when they concern a reproducible security weakness in this project's code, website, configuration, or deployment. Examples include authentication or authorization flaws, exposure of secrets or private data, and security misconfiguration.

Issues in third-party services should be reported to the relevant provider as well. General bugs, feature requests, and non-security website feedback can be submitted through [GitHub Issues](https://github.com/simthandilemthwesi/gbnb-site/issues).

Thank you for helping protect the George Bakhanyiselwa Nguwe Bawo NPC project and the people it serves.
